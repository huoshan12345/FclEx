# FclEx.Xunit.v3.SourceGenerator

xUnit v3 source generator for FclEx test serialization helpers.

## What Is Included

- xUnit v3 variant of the FclEx xUnit serialization generator.
- Shared Roslyn/source-building utilities.
- Analyzer-config helpers used by the v3 generator path.

## Usage Notes

- This project is packaged as an analyzer dependency of `FclEx.Xunit.v3`.
- It is not intended as a runtime library.
- This generator is used by `FclEx.Xunit.v3`; there is no separate xUnit v2 generator package.
