# FclEx.Xunit

xUnit v2 helpers for FclEx test projects.

## What Is Included

- `AssertEx` extended assertions.
- Conditional and local-only fact/theory attributes.
- xUnit output helper and logger provider integration.
- Testing sequence helpers and breakable enumerables.
- Equality exception helpers.
- Serialization helpers and source-generator support for xUnit serializable values.

## Usage Notes

- Use this package with xUnit v2.
- Use `FclEx.Xunit.v3` for xUnit v3 test projects.
- The package includes an analyzer/source-generator companion for generated serialization helpers.
